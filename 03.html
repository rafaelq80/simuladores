Latch SR

O menor circuito capaz de lembrar um valor (0 ou 1): duas peças ligadas uma na outra, cada uma de olho na saída da outra.

Circuito com portas OR + NOT

Tabela verdade (toque numa linha para testar)

S R Q Q O que acontece
0 0 igual ao de antes igual ao de antes Guarda o valor
0 1 0 1 Apaga: grava 0
1 0 1 0 Liga: grava 1
1 1 0 0 Proibido

Latch SR volátil

Célula NAND não volátil

1 célula = 1 bit (modo SLC). As bolinhas são elétrons, não bits: com carga vale 1, vazia vale 0.

Linha do tempo

Linha tracejada = valor desconhecido (sem energia). Compare o Q (que esquece ao desligar) com o NV (que continua guardado).
